# Almoxarifado

**Aluno(a):** Nauhana Cristine Branco da Costa

**Turma:** Técnico em Desenv. de Sistemas - Noturno

## Descrição

Projeto desenvolvido em Python para gerenciar o estoque de um almoxarifado, permitindo cadastrar produtos, consultar quantidades, registrar entradas e saídas e calcular o valor total do estoque.

## Como executar os testes

No terminal, execute o comando:

`py -m testes.teste_almoxarifado`
